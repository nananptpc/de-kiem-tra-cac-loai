🔄 Công cụ chuyển CSV ➜ data.js

Dán nội dung file content.csv vào ô bên dưới (bao gồm dòng tiêu đề).

📄 Nội dung file data.js (copy toàn bộ)

💡 Hướng dẫn:
1. Dán nội dung file content.csv (có header) vào ô trên.
2. Nhấn "Chuyển đổi".
3. Copy kết quả trong khung, dán vào file data.js (thay thế toàn bộ nội dung cũ).
4. Lưu và commit lên GitHub. Trang index.html sẽ tự động dùng dữ liệu mới.
